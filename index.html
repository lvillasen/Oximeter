Oxímetro de Pulso Digital

CIIEC-BUAP

08 de Mayo, 2026

Código Fuente

Se describe la construcción y operación de un oxímetro digital basado en un sensor MAX30102 conectado a un ESP32, capaz de adquirir y procesar en tiempo real señales fotopletismográficas (PPG) obtenidas mediante LEDs rojo e infrarrojo. El sistema permite estimar la saturación de oxígeno en sangre (SpO₂) y la frecuencia cardiaca a partir del análisis de la absorción óptica pulsátil del tejido. Además, el dispositivo captura la forma completa de la onda PPG, permitiendo la extracción de parámetros fisiológicos relevantes, como la variabilidad de la frecuencia cardiaca (HRV), características temporales y morfológicas del pulso y otros indicadores asociados al estado cardiovascular y hemodinámico, lo que posibilita su aplicación en monitoreo no invasivo y análisis avanzado de señales biomédicas.

¿Cómo funciona un Oxímetro Digital?

  1. Emisión de luz mediante LEDs:
    • El oxímetro utiliza LEDs rojo e infrarrojo integrados en un sensor como el MAX30102.
    • El sensor se coloca en contacto con la piel, normalmente en el dedo.
    • Los LEDs iluminan el tejido y los vasos sanguíneos con diferentes longitudes de onda.
  2. Interacción de la luz con la sangre:
    • La hemoglobina oxigenada y desoxigenada absorben la luz de manera diferente.
    • Parte de la luz es absorbida y otra parte es reflejada hacia el fotodetector.
    • La cantidad de luz detectada cambia con cada latido cardíaco debido al flujo pulsátil de sangre arterial.
  3. Detección de la señal óptica:
    • Un fotodetector integrado mide la intensidad de la luz reflejada.
    • El sensor convierte estas variaciones ópticas en señales digitales.
    • Un microcontrolador como el ESP32 procesa la información en tiempo real.
  4. Obtención de la señal PPG:
    • Componente AC (pulsátil): cambia con cada latido cardíaco y representa la onda de pulso arterial.
    • Componente DC (lenta): depende del tejido, respiración, perfusión y otros factores fisiológicos.
  5. Cálculo de SpO₂ y frecuencia cardíaca:
    • Comparando las señales roja e infrarroja se estima la saturación de oxígeno en sangre (SpO₂).
    • A partir de los pulsos detectados también se calcula la frecuencia cardíaca en latidos por minuto (LPM).

Tipos de sensores ópticos PPG

  • Transmisivo: la luz atraviesa el tejido y es detectada al lado opuesto (ejemplo: oxímetros de dedo).
  • Reflectivo: el fotodetector se encuentra junto a los LEDs y mide la luz reflejada (ejemplo: relojes inteligentes y sensores MAX30102).

Principales aplicaciones de un Oxímetro Digital

  1. Medición de saturación de oxígeno (SpO₂).
  2. Frecuencia cardíaca: cálculo del pulso en latidos por minuto.
  3. Variabilidad de la frecuencia cardíaca (HRV): análisis de los intervalos entre pulsos.
  4. Análisis de la onda PPG: estudio de características temporales y morfológicas del pulso arterial.
  5. Monitoreo cardiovascular no invasivo.
  6. Monitorización durante el sueño y ejercicio.
  7. Investigación biomédica y educativa: desarrollo de sistemas portátiles basados en sensores ópticos y ESP32.

Codigo para programar el microcontolador ESP32 usando Arduino IDE. Este código permite leer la señales del LED rojo y del LED infrarojo (IR) del sensor MAX30102 a razón de 200 Hz y mandar los datos a la PC a través del puerto serie a 115200 baudios. 


      #include <Wire.h>
      #include "MAX30105.h"

      MAX30105 particleSensor;

      const byte SAMPLE_AVG    = 1;
      const byte LED_MODE      = 2;      // Red + IR
      const int  SAMPLE_RATE   = 200;    // SPS
      const int  PULSE_WIDTH   = 411;    // µs
      const int  ADC_RANGE     = 4096;
      const byte LED_BRIGHTNESS = 70;

      void setup() {
          Serial.begin(115200);  // más rápido → menos latencia Serial

          Wire.begin(21, 22);
          Wire.setClock(400000);

          if (!particleSensor.begin(Wire, I2C_SPEED_FAST)) {
              Serial.println("# ERROR: MAX30102 no encontrado");
              while (1);
          }

          particleSensor.setup(
              LED_BRIGHTNESS,
              SAMPLE_AVG,    // 1 = sin promedio → máxima resolución temporal
              LED_MODE,
              SAMPLE_RATE,
              PULSE_WIDTH,
              ADC_RANGE
          );
          particleSensor.clearFIFO();
          Serial.println("# ir red t_ms");
      }

      void loop() {
          if (particleSensor.available() == 0) {
              particleSensor.check();  // pedir al sensor que llene el FIFO
              return;
          }

          uint32_t ir  = particleSensor.getFIFOIR();
          uint32_t red = particleSensor.getFIFORed();

          particleSensor.nextSample();

          float t_ms = micros() * 0.001f;
          char line[48];
          int len = snprintf(line, sizeof(line), "%lu %lu %.2f\n", red, ir, t_ms);
          Serial.write((uint8_t*)line, len);
      }
